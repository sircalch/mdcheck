# Security policy

## Supported versions
Security fixes are applied to the latest released version of MDCheck.

## Reporting a vulnerability
Please **do not** open a public issue for security problems. Report them privately using GitHub's "Report a vulnerability" option in the repository's *Security* tab, or by email to andres.monreal@ues.mx with:
- a description of the problem and its impact,
- steps or a minimal example to reproduce it,
- the MDCheck version and your Python version.

You can expect an acknowledgement in a reasonable time. This is a small research-software project maintained by one person, so please be patient; coordinated disclosure is appreciated.
