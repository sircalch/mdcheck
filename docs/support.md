# Support and contributing

## Getting help

Ask questions and report bugs in the [issue tracker](https://github.com/sircalch/mdcheck/issues). Please include:

- the MDCheck version (`mdcheck --version`);
- the command or code you ran and the full error message;
- when possible, a small input file that reproduces the problem.

## What to expect

MDCheck is maintained by one person alongside research and teaching. Issues and pull requests are answered on a best-effort basis; the aim is to acknowledge new reports within two weeks. Security problems are handled privately as described in [`SECURITY.md`](https://github.com/sircalch/mdcheck/blob/master/SECURITY.md).

## How decisions are made

The maintainer, Andrés Monreal Hernández ([@sircalch](https://github.com/sircalch)), reviews and merges changes. Changes that alter a scientific result, a default threshold or the meaning of a status are discussed in an issue first, and are documented in the [changelog](https://github.com/sircalch/mdcheck/blob/master/CHANGELOG.md) and in this documentation.

## Contributing

Bug reports, documentation fixes, new tests and code are welcome. See [`CONTRIBUTING.md`](https://github.com/sircalch/mdcheck/blob/master/CONTRIBUTING.md) for the development set-up and what a good pull request includes. By participating you agree to follow the [code of conduct](https://github.com/sircalch/mdcheck/blob/master/CODE_OF_CONDUCT.md).
