# Citing MDCheck

If MDCheck helps your research, please cite it. The repository's [`CITATION.cff`](https://github.com/sircalch/mdcheck/blob/master/CITATION.cff) is the canonical record; GitHub's "Cite this repository" button uses it.

The all-versions DOI always resolves to the latest archived release: [10.5281/zenodo.22217568](https://doi.org/10.5281/zenodo.22217568). To cite the exact version you used, take the version DOI from the Zenodo record.

From the command line:

```bash
mdcheck cite
```
